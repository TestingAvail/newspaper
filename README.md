# Newspaper

Автоматический сборщик и агрегатор новостей/лент, работающий на базе GitHub Actions.

## Назначение
Репозиторий предназначен для регулярного скачивания, обработки и обновления новостных данных в автоматическом режиме без поднятия постоянной инфраструктуры на серверах.

## Как это работает
1. Скрипт в составе воркфлоу (`.github/workflows/newspaper.yml`) запускается по расписанию через cron.
2. Собирает актуальные данные из настроенных источников.
3. Производит парсинг и сохранение результатов в репозиторий.
